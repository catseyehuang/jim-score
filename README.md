# ⭐ JIM 計分板

一個專為親子設計的行為計分工具，幫助記錄孩子的好行為，並用積分兌換獎勵。

🌐 **使用網址：** https://catseyehuang.github.io/jim-score

---

## 📖 專案簡介

這是一個給國小低年級孩子使用的行為積分工具。
爸媽可以快速記錄孩子的好行為或壞行為，孩子則可以用累積的分數兌換喜歡的獎勵。

---

## ✨ 功能特色

- ⭐ **即時計分** — 一鍵記錄加分、扣分、警告行為
- 🎁 **獎勵商店** — 用分數當貨幣兌換不同獎勵
- 🔐 **PIN 碼保護** — 防止孩子自己亂加分
- 📋 **歷史紀錄** — 查看最近30筆行為記錄
- ☁️ **雲端同步** — 資料存在 Google Sheets，手機電腦都能看
- 📱 **手機友善** — 可加入主畫面當 App 使用

## 🚀 安裝與設定步驟

### Step 1：建立 Google Sheets

1. 前往 [sheets.google.com](https://sheets.google.com) 建立新試算表
2. 命名為「寶貝計分板」
3. 建立4個工作表：`紀錄`、`行為項目`、`獎勵項目`、`設定`

**各工作表欄位：**

`紀錄`
```
A1: 時間戳記  B1: 行為名稱  C1: 分數變動  D1: 類型  E1: 備註
```

`行為項目`
```
A1: 行為名稱  B1: 分數  C1: 類型
```

`獎勵項目`
```
A1: 獎勵名稱  B1: 所需分數  C1: 狀態
```

`設定`
```
A1: 項目   B1: 值
A2: PIN碼  B2: 1234
A3: 總分   B3: 0
```

---

### Step 2：填入預設資料

**行為項目（從第2行開始）：**

| 行為名稱 | 分數 | 類型 |
|---------|:---:|:---:|
| 完成作業 | 2 | 加分 |
| 主動幫忙家事 | 3 | 加分 |
| 準時上床睡覺 | 2 | 加分 |
| 主動閱讀 | 2 | 加分 |
| 表現很棒 | 5 | 加分 |
| 打人或罵人 | -3 | 扣分 |
| 說謊 | -3 | 扣分 |
| 不聽勸告再犯 | -2 | 扣分 |
| 頂嘴 | 0 | 警告 |
| 不收玩具 | 0 | 警告 |

**獎勵項目（從第2行開始）：**

| 獎勵名稱 | 所需分數 | 狀態 |
|---------|:---:|:---:|
| 看一集卡通 | 10 | 上架 |
| 買一包零食 | 15 | 上架 |
| 去公園玩 | 20 | 上架 |
| 選一個家庭活動 | 30 | 上架 |
| 買玩具（小） | 50 | 上架 |

---

### Step 3：建立 Google Apps Script

1. 在 Google Sheets 點選「擴充功能」→「Apps Script」
2. 清除預設內容，貼上 `apps-script/Code.gs` 的程式碼
3. 儲存專案，命名為「計分板API」

---

### Step 4：部署 Apps Script

1. 點「部署」→「新增部署作業」
2. 類型選「網頁應用程式」
3. 設定：
   - 執行身份：**我（自己的帳號）**
   - 誰可以存取：**所有人**
4. 點「部署」並完成授權
5. 複製產生的 `exec` 網址

---

### Step 5：設定 GitHub Pages

1. 在 GitHub 建立 repo：`kids-score`（Public）
2. 將 `index.html` 上傳至 repo 根目錄
3. 進入 Settings → Pages → Branch 選 `main` → Save

網址格式：`https://{你的帳號}.github.io/kids-score`

---

### Step 6：首次使用

1. 開啟網址，系統會要求設定 PIN 碼
2. 輸入4位數 PIN（之後用來保護家長功能）
3. 設定完成即可開始使用！

## 🔧 日常維護
